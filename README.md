# marterial blog
-# like marmite but material 3 so marterial.. get it heh 

---

Soo what is this repo?? The project doesnt talk about the blog itself rather then the themes it has..
Entire page has a material 3 insired theme that showcases what you can do in css and JS only.. 

One of its main feauture is **dynamic color scheme theming** which takes main color of a blog post thumbnail and generates the color scheme same as android does that with apps having color from wallpaper :3 
The blog also has custom material 3 expressive type of author, tags, posts headers which look really sick imo. It has every element from the original marmite static page builder reworked.
