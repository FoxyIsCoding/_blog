The creation of the blog

Soo before i get into any of the feautures of this blog i want to talk about how i made it :P The blog uses a static site generator called marmite which is a rust based static site generator. I chose this because acording to people it highly customizable and is very fast. I also wanted to learn rust so this was a good opportunity to do so

It was not as cuztomizable as i thought it would be but it was still pretty good. I had to make a lot of changes to the codebase to get it to work the way i wanted it to but in the end it was worth it.. This project is now the most complex and nicest looking theme of marmite ever made 😭

What can you do here?

Well you can read the blog posts of course lol but you can also experiment with the theme.. Bcuz this project isnt about the blog posts, isnt about rust static site generators, its about the theme..

Thats also why i would like you to not downvote this project if you dont like the blog posts, i want you to downvote it if you dont like the theme.. As the theme is the main focus of this project and the blog posts are just there to show off the theme..

I always wanted to make a blog but i never had the motivation to do so, but this project gave me the motivation to actually make one.. I always see all of those cool asf blogs and i wonder how they are made and how they look so good, and now i know (except that like noone uses marmite so ye 😭)

The theme has a material 3 design inspired looks. The author section and tags section uses nice smooth animations and the blog posts are displayed in a nice grid layout. The theme also has a dark mode which is pretty cool :P ( fun fact: it has white mode apparently in the css but i was lazy to try how it looks 😭 )

alsoo a cool asf feature..

yk what google has.. Any android 12+ (or 13+ i dont remember) phone adapts the color scheme of the phone to the apps.. well this blog does that too :P it adapts the color scheme of the blog to the banner image.. This is done by extracting the dominant color from the banner image and using it as the primary color of the theme.. This is a pretty cool feature and it makes the blog look really nice :3

Conclusion

Overall i am pretty happy with how the blog turned out.. It was a lot of work to get it to look the way i wanted it to but in the end it was worth it.. I hope you like it too :3
